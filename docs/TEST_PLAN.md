# Orbit Ledger: Comprehensive Test Plan (TEST_PLAN)

## 1. Testing Strategy and Structure

Testing is organized into four rigorous layers to guarantee zero runtime surprises during evaluation:

1. Layer A Unit Tests (`node:test`): Validates cryptographic hashing, block linking, Merkle tree math, duplicate rejection, and consensus state machines in pure JavaScript.
2. Layer B Smart Contract Tests (Hardhat Mocha/Chai): Validates EVM access control, anchoring, on-chain SHA-256 Merkle proofs, ERC20 purchases, integer conjunction arithmetic, and ERC721 minting.
3. System Integration & End-to-End Tests: An automated verification runner (`scripts/demo_e2e.js`) executing the complete operational lifecycle from data ingestion to on-chain verification.
4. Preflight System Health Check (`scripts/preflight.js`): Automated sanity script verifying ports, Node version, Ganache RPC connectivity, contract addresses, and data integrity.
5. Manual Verification Checklist: Step-by-step procedures for interactive wallet connection, Sepolia testnet execution, and Etherscan block inspection.

## 2. Automated Test Matrix

## 3. End-to-End System Test (`scripts/demo_e2e.js`)

The end-to-end script executes the entire system workflow autonomously and exits with non-zero status if any step fails:

1. Step 1: Prepares raw data and seeds Layer A deterministic chain (25 blocks of 40 records).
2. Step 2: Confirms Layer A internal cryptographic validity (`isValidChain() === true`).
3. Step 3: Deploys all four Solidity contracts to Ganache local RPC.
4. Step 4: Iteratively anchors all 25 block Merkle roots to `DebrisLedger.sol`.
5. Step 5: Selects Record #17 from Block #8, generates SHA-256 Merkle proof in JavaScript, and executes `DebrisLedger.verifyRecord()` on Ganache; verifies returned value is `true`.
6. Step 6: Simulates 4-node PBFT consensus with Node 4 offline; confirms block commit with 3/4 signatures.
7. Step 7: Runs SGP4 conjunction screening on candidate TLEs; derives integer coordinates; submits report to `ConjunctionMonitor.sol`.
8. Step 8: Confirms issuance of ERC721 `AlertCertificate` Token #1.
9. Step 9: Re-submits the identical report; verifies contract reverts with `ConjunctionAlreadyReported`.
10. Step 10: Executes ERC20 token transfer and `DebrisLedger.buyAccess()` flow; verifies access entitlement granted.

## 4. Preflight Health Verification Script (`scripts/preflight.js`)

Executed before any live demonstration via `npm run preflight`. Validates:
- Node.js Version: Exactly v20.x (fails if Node 24 or unsupported version detected).
- Port Availability: Port 8545 (Ganache) and Port 3000 (API) are available or responding.
- Ganache RPC: Connects to `http://127.0.0.1:8545`; queries `eth_blockNumber` and accounts.
- Contract Deployments: Checks `deployments/ganache.json` exists and bytecode is present at addresses.
- Layer A Data Integrity: Verifies `data/seed_records.json` contains 1,000 records across 25 blocks.
- Output: Prints green checkmarks or explicit failure instructions with remediation steps.
